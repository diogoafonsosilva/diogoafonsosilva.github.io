01 O projeto

O que é

A app mostra para onde vai o dinheiro e o que isso significa: um painel com projeção de fim de mês, alertas quando uma categoria foge do normal e comparação com o ciclo anterior.

Além do registo do dia a dia, traz calculadoras pensadas para Portugal — crédito habitação, IMT e imposto do selo, salário líquido, IUC e recibos verdes. A versão pessoal continua privada; a demo é um deploy separado, com uma persona fictícia e uma base de dados que se renova sozinha.

02 Funcionalidades

O que faz

  1. Painel com insights automáticos sobre os gastos
  2. Movimentos, orçamentos por categoria, património e metas
  3. Calculadoras financeiras com regras portuguesas
  4. Calendário de movimentos
  5. Modo escuro e interface totalmente usável no telemóvel
  6. Demo pública com dataset fictício, editável em tempo real

04 Porquê assim

Decisões técnicas

Servidor lê, cliente escreve

As páginas vão buscar os dados diretamente no servidor. As alterações passam por uma camada de serviços e a página atualiza a seguir — sem estado duplicado no browser.

Lógica financeira isolada e testada

Insights e calculadoras são funções puras, sem base de dados, cobertas por testes. É a parte onde um erro custa mais.

Demo separada da app real

A versão pública é um projeto à parte, com dados inventados. Os dados verdadeiros nunca saem do computador.
